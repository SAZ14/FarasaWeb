# Farasa — Website

Minimal, static marketing site for **Farasa**, a provider of real-world physical AI
training data collected on active construction sites.

## Stack

Plain HTML, CSS, and vanilla JavaScript — no build step, no dependencies.

```
index.html      Page markup (all sections)
css/style.css   Design system and layout
js/main.js      Scroll-reveal and header micro-interactions
```

## Run locally

Any static file server works:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
